# Objection Taxonomy Reference

Common commercial objections across SaaS, Ecommerce tools, and Product Landing Pages, with placement guidelines.

## 1. "Will this mess up my live store / data?"
- **When it surfaces:** The moment an export, sync, or app integration is mentioned.
- **Answer pattern:** Explicit read-only assurance, non-destructive preview, manual review before write.
- **Best placement:** Directly below the primary CTA or adjacent to the integration input field.

## 2. "How long does this take to set up?"
- **When it surfaces:** Above the fold or near the CTA.
- **Answer pattern:** "Takes 30 seconds. No app installation or API keys required."
- **Best placement:** Hero subheadline microcopy or CTA helper text.

## 3. "What happens if my store has more products than the plan allows?"
- **When it surfaces:** Reading the pricing table or seeing scan limits.
- **Answer pattern:** Clear explanation of sample audits vs full catalog unlocks, transparent tier pricing.
- **Best placement:** Pricing card footnotes or FAQ section.

## 4. "Can I cancel anytime or am I locked in?"
- **When it surfaces:** Right before checkout / upgrade modal.
- **Answer pattern:** "Month-to-month. Cancel with one click inside settings. No contracts."
- **Best placement:** Below checkout button or within pricing modal guarantee badge.
